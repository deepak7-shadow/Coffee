# Broven — Artisan Coffee Brewery (Bangalore · 2026)

A modern, interactive specialty coffee web application built with React, Vite, Framer Motion, and Tailwind CSS.

## Features
- **3D Interactive Hero**: Full-window cursor tracking with spring physics, natural 3D tilt, and zero-gravity floating levitation.
- **Interactive Order Drawer**: Slide-over cart with live item count badge, promo codes (`BREW15`), free delivery meter, and checkout animation.
- **Artisan Menu Customizer**: Filter by categories, select cup sizes (8oz, 12oz, 16oz), and inspect aroma flavor profiles.
- **Interactive Roast Lab**: Roast spectrum profiling and real-time barista extraction ratio calculator with live brew stopwatch.
- **Coffee Sommelier Quiz**: 3-step personalized brew finder modal with instant add-to-cart recommendation.
- **Patron Acclaim & Reviews**: Community ratings with interactive review submission modal.
- **Bangalore Flagship Locations**: Indiranagar and Koramangala tasting ateliers, Chikmagalur estate reserve.

## Getting Started

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build
```
